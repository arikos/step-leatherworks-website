STEP LEATHERWORKS LIMITED — WEBSITE
=================================

Files
-----
index.html        Home page
products.html     Product catalogue (7 categories)
wholesale.html    Bulk supply information
training.html     Formal training (UVTAB curriculum)
capacity.html     Capacity building programs & partner timeline
about.html        Company story, team, awards
contact.html      Contact details & inquiry form
assets/css/       Stylesheet
assets/js/        Language switcher + mobile menu + inquiry form
assets/img/       All photos

How to view
-----------
Open index.html in any web browser (double-click it).

How to publish (free options)
-----------------------------
1. Netlify Drop — go to app.netlify.com/drop and drag this whole folder in. Done.
2. Vercel / GitHub Pages — upload the folder as a project.

Notes
-----
- The inquiry form opens the visitor's email app (no server needed).
- Language switcher: English, Kiswahili and Luganda are live; Luo is a draft
  and Ateso is placeholder — have native speakers review before launch.
- Placeholder images (ladies' shoes, bags, wallets) live in assets/img/
  named placeholder-*.jpg — replace them with real product photos
  keeping the same filenames to update the site automatically.
